# Opening in Power BI Desktop

1. Install **Power BI Desktop (Nov 2023 or newer)**.
2. In Desktop: **File → Options and settings → Options → Preview features**.
3. Enable:
   - Power BI Project (`.pbip`)
   - TMDL view/model definition
4. Restart Desktop.
5. Open `/powerbi/RunRateTracker.pbip`.
6. Refresh model.
7. Make report/model edits and save.
8. Commit via VS Code or GitHub Desktop.
